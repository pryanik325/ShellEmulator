# Эмулятор оболочки ОС

Эмулятор языка оболочки UNIX-подобной ОС (Вариант №10).


## Этап 1. REPL

Минимальный прототип с GUI, парсером кавычек
и командами-заглушками.

### Возможности

- Графическое окно (tkinter)
- Заголовок: `Эмулятор - [username@hostname]`
- Парсер с поддержкой кавычек
- Команды-заглушки: `ls`, `cd`
- Команда `exit` — завершение работы
- Обработка ошибок
